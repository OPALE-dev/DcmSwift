# ``DcmSwift``

Read, write, validate, render, and exchange DICOM data with a cross-platform
Swift package.

## Overview

DcmSwift provides a Foundation-first DICOM library and a set of focused command
line tools. The library supports Part 10 files, data sets, native XML and JSON,
DICOMDIR, image rendering and codecs, structured reports, and DIMSE networking.

Start with <doc:GettingStarted> when embedding the library. For shell workflows,
see <doc:CommandLineTools> and the individual command guides. The qualification
documents describe what is implemented, what has been independently checked,
and what remains deliberately limited.
